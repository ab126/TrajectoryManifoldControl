# Validation integration and research gates

Protocol established 2026-10-17 before new controller experiments.

1. Pin upstream; inspect its license, manuscript, plant, datasets, metrics and
   controller entry points. Call upstream functions in a separate Python process
   so its `src`/`scripts` imports cannot accidentally resolve to this repository.
2. Verify six authored starts and a fixed prefix of three random starts. Compare
   archived L gains and archived per-case results before expensive training.
   Reproduced training is a new artifact, not the unavailable original checkpoint.
   Stop development on substantial unexplained baseline discrepancies.
3. Add A (legacy), B (unwrapped recovery), C (periodic recovery) scoring to every
   arm. Preserve unwrapped simulator states and the upstream A definition.
4. Diagnose the unchanged learned decoder and CEM on measured held-out episodes
   and separate tuning starts: coordinate consistency, errors by horizon/state,
   Jacobian singular values, input sensitivity, equilibrium residual, candidate
   input replay, optimization acceptance and feedback timing. Evaluate L plans
   under the learned objective only as diagnostics.
5. Only after the baseline gate, add independent configurations for feedback
   interval, safe CEM, bounded differentiable optimization, multistep training,
   periodic angle cost and terminal-window cost/horizon. Preserve originals.
6. Select using validation episodes and tuning starts generated by a different
   saved seed from the final starts. Freeze hashes/configuration before running
   final C200/fresh200, seeds 0/1/2. Final scores cannot select configurations.
7. Report paired outcomes within each fitted seed, latency (including 20 ms
   deadline misses), failures and the exact gap to L. Add 60 s and mismatch/delay
   tests only after nominal reproducibility. No plant predictions/Jacobians or
   plant-parameter queries in learning, planning, or selection.

## Compute staging

Run import/metric tests first, then inexpensive archived-gain L replay, then at
most one dev-model reconstruction and nine baseline cases for diagnostics.
Record timings before allocating the three-seed/full evaluation. No broad sweep.
Checkpoints/data/raw traces are intentionally absent from upstream Git; importing
published result tables is evidence inspection, not reproducing an experiment.
