Open index.html for all 200 cases and eight offline animations. Each case has a 12-panel PNG/PDF and NPZ with normalized/physical states, controls, energies, work, power, interval accelerations, rod geometry, cost components, safety margins, branches and solve times. Original source trajectories were not edited. All figures retain the complete 20 seconds. Energy/work/cost are derived, not measured sensor data. Notebook: ../../notebooks/gate_a_examples.ipynb. Its outputs are prepopulated; trust the notebook to run embedded animation scripts or open the standalone HTML examples. Re-running cells needs NumPy, Matplotlib and IPython in a notebook kernel; the private scientific environment does not contain a Jupyter kernel.
